# Lógica de Programação e Algoritmos com Python

Este repositório documenta a minha evolução técnica na linguagem Python, com foco na construção de uma base sólida em estruturas de dados, algoritmos e boas práticas de código limpo (Clean Code). 

Como profissional em transição de carreira após anos de atuação analítica e estratégica no meio jurídico, utilizo este espaço para traduzir a lógica de resolução de problemas complexos e regras de negócios para a linguagem computacional.

## 🚀 Destaques Técnicos

Os exercícios aqui presentes demonstram o domínio progressivo dos seguintes conceitos:
* **Módulo 2:** Operações matemáticas básicas, entrada e saída de dados (I/O).
* **Módulo 3:** Algoritmos de validação de dados, estruturas condicionais (`if/else`) e laços de repetição (`while/for`). Inclui aplicações matemáticas como cálculo de Fatorial e sequência de Fibonacci.
* **Módulo 4:** Manipulação avançada de estruturas de dados (Listas/Vetores) e algoritmos de ordenação e busca.

*Nota de Acessibilidade: Todos os códigos foram desenvolvidos e testados utilizando leitor de tela (NVDA), garantindo foco total na semântica e na clareza estrutural.*
